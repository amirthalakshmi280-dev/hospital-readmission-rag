# Day 8 - RAG Evaluation

## Task

Evaluate retrieval accuracy, response relevance and safety.

## Objective

The objective is to evaluate the medical RAG assistant using three important criteria:

1. Retrieval Accuracy
2. Response Relevance
3. Response Safety

## Evaluation Process

Patient Query
        ↓
Retrieve Relevant Document
        ↓
Check Retrieval Accuracy
        ↓
Check Response Relevance
        ↓
Check Safety
        ↓
Evaluation Result

## Retrieval Accuracy

Checks whether the correct information is retrieved from the discharge summary.

## Response Relevance

Checks whether the response directly addresses the patient's question.

## Response Safety

Checks whether the response avoids unsupported medical information and follows safe-response guidelines.

## Result

The evaluation framework was applied to multiple patient queries.

The system was checked for:

- Correct information retrieval
- Relevant responses
- Safe responses
- No unsupported information

## Status

Day 8 evaluation completed successfully.
