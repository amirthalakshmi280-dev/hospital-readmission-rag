# Day 12 - Medical Assistant Interface

## Task

Develop medical assistant interface.

## Objective

The objective is to provide a simple graphical interface for the medical RAG assistant.

## Interface Features

The interface provides:

- Question input box
- Ask Question button
- Clear button
- Response display area
- Source citation

## Working Process

Patient
   ↓
Enter Question
   ↓
Medical RAG Assistant
   ↓
Retrieve Relevant Information
   ↓
Display Response
   ↓
Show Source

## Technology

Python
Tkinter
Scikit-learn
TF-IDF
Cosine Similarity

## Safety

The interface displays information retrieved from the discharge summary.

It does not create unsupported medical information.

If relevant information is not found, the assistant informs the user.

## Status

Day 12 medical assistant interface completed successfully.

## Note

This project uses synthetic data for educational purposes and is not a medical diagnostic or clinical decision-making system.
