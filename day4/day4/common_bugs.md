# Common Programming Bugs

## 1. Syntax Error

A syntax error occurs when Python code does not follow the correct syntax.

Example: Missing closing bracket or quotation mark.

## 2. Name Error

A NameError occurs when a variable or function is used without being defined.

Example: Using a variable before defining it.

## 3. Type Error

A TypeError occurs when an operation is performed on incompatible data types.

Example: Adding a number to a text value.

## 4. Index Error

An IndexError occurs when an invalid list index is accessed.

Example: Accessing an index that does not exist in a list.

## 5. Key Error

A KeyError occurs when a dictionary key does not exist.

Example: Trying to access a key that is not present in the dictionary.

## 6. Logic Error

A logic error occurs when the program runs but produces an incorrect result.

## 7. File Handling Error

A file handling error occurs when a file does not exist or does not have the required permissions.

## 8. Common Prevention Methods

- Test code regularly.
- Validate input data.
- Use meaningful variable names.
- Handle exceptions.
- Review code before deployment.
