# Coding Standards

## 1. Naming Conventions

- Use meaningful variable names.
- Use lowercase with underscores for Python variables and functions.
- Use descriptive names for classes and methods.

Example: patient_age = 65

## 2. Code Formatting

- Use consistent indentation.
- Keep lines readable.
- Add spaces around operators.
- Follow a consistent coding style.

## 3. Functions

- Keep functions small and focused.
- Use meaningful function names.
- Avoid unnecessary duplicate code.

## 4. Comments

- Add comments when the logic is not obvious.
- Keep comments short and useful.
- Avoid unnecessary comments.

## 5. Error Handling

- Handle expected errors using try-except.
- Do not hide errors silently.
- Provide useful error messages.

## 6. Documentation

- Add README files for projects.
- Document important functions and workflows.
- Keep documentation updated.

## 7. Code Quality

- Avoid duplicate code.
- Remove unused variables and imports.
- Test code before deployment.

## Summary

Good coding standards improve readability, maintainability, reliability, and collaboration.
